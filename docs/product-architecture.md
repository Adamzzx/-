# 产品架构与后续开发范围

定位：全球中文用户的交易所比较和决策平台。收入来自推荐注册、明确标注的广告和赞助内容。比较优先，新闻不作为首页主轴。独立品牌、文案、视觉和资产，不复制参考站。

## 信息架构

简体中文前台 `/zh-cn/`；未来 `/zh-tw/`、`/en/`。语言与地区资格独立。

目标路径：`/exchanges/{slug}/`、`/compare/{a}-vs-{b}/`、`/reviews/{slug}-review/`、`/best/best-crypto-exchanges/`、`/register/{slug}/`、`/fees/{slug}/`、`/guides/{slug}/`、`/security/{slug}/`、`/tokenized-stocks/`，均置于语言前缀下。推荐跳转 `/go/{slug}/` 不带语言前缀。

主导航：交易所比较、交易所、榜单、指南、代币化股票。页脚：编辑政策、比较方法、商业披露、隐私政策、使用条款、风险说明、联系与纠错。

## 页面与组件

页面：资料中心、独立评测、两家比较、场景榜单、注册说明、操作指南、专题。资料与评测不能重复同一内容。组件：交易所卡片、比较表、筛选器、费用表、资格提示、来源与核验日期、作者、商业标识、统一推荐按钮、相关内容、语言切换及广告容器。

## 数据与后台

稳定交易所 ID 关联多语言资料、产品资格、条件化费用、网络支持、安全证据、优惠、内容、来源和排名方法版本。所有动态事实保留核验时间与适用条件；未知与零值必须区分。

当前数据库提供管理员、媒体、交易所、文章、推荐入口、点击记录。细化费用、地区资格、产品、方法版本和编辑角色属于后续阶段。所有当前后台用户拥有管理能力。

CMS 目标：审核流程、私有预览、版本、多角色、结构化内容块、翻译关联、复核提醒、活动管理和缓存更新。当前已实现草稿/发布、基础多语言字段和中心推荐入口。

## 推荐系统

正文不写死推荐链接，以交易所/活动实体引用。服务端校验已审核目的地和有效期，302 跳转，禁止任意 URL 参数。推荐链接标记 sponsored/nofollow；失效入口回到注册说明。不把佣金与编辑排名挂钩。

初期每家交易所一个通用入口；未来扩展语言、地区和活动优先级。点击与注册转化分开，转化依赖合作方报表或回传。

## SEO、多语言、移动与性能

内容服务端渲染。已发布译文具有独立 canonical 与双向 hreflang；未翻译不生成空页面。固定比較内容保持唯一顺序和规范地址；参数筛选不索引。Sitemap 只纳入适合索引的内容。结构化数据必须符合实际页面，不承诺搜索特殊展示。

移动端从 360px 验收，比较表容器允许滚动，正文禁止横向溢出。目标 WCAG 2.2 AA。预留广告高度，点击区域约 44px。真实用户 p75 目标：LCP ≤2.5s、INP ≤200ms、CLS ≤0.1；当前未取得真实用户性能数据。

正式规模化时引入发布后缓存失效和增量生成；首阶段动态读取保证编辑可立即呈现。

## 安全、分析与运营

后台强认证和审计，后续 MFA、细分权限；密钥不提交，生产数据库独立。限制上传格式、富文本能力、目的域名及外链检查，防止 XSS、开放跳转与 SSRF。正式上线配置 CSP、邮件、备份恢复、限流和隐私策略。

分析目标：比较开始/完成、筛选、推荐点击、广告点击、语言切换、纠错提交。最小采集，不记录交易所凭据、钱包地址或邮箱。当前仅记录推荐点击。

首发顺序：可运行基础 → 核验资料 → 重点评测和比较 → 榜单及指南 → 注册活动 → 广告与分析 → 多语言。代币化股票必须说明发行主体、托管、赎回、持有人权利和地区条件。
