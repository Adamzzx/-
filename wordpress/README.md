# WordPress implementation

Standalone classic theme and companion plugin for existing PHP/MySQL hosting. The Next.js project is preserved unchanged. Components are GPL-2.0-or-later.

Build uploadable archives: `python wordpress/build.py`.

See [安装说明](安装说明.md) for owner-facing installation. No secrets, referral destinations or invented exchange facts are included in the archives.

Local test environment (isolated from the Next.js database and Hostinger):

```bash
docker compose -f wordpress/tests/compose.yaml up -d wordpress
docker compose -f wordpress/tests/compose.yaml run --rm -T cli wp core install --url=http://localhost:8088 --title='交易所指南测试站' --admin_user=smoke-admin --admin_password=local-test-only --admin_email=smoke@example.invalid --skip-email
docker compose -f wordpress/tests/compose.yaml run --rm -T cli wp plugin activate exchange-guide
docker compose -f wordpress/tests/compose.yaml run --rm -T cli wp theme activate exchange-guide
docker compose -f wordpress/tests/compose.yaml run --rm -T cli wp rewrite structure '/%postname%/'
docker compose -f wordpress/tests/compose.yaml run --rm -T cli wp eval 'cg_setup_pages(true); update_option("blog_public",0);'
docker compose -f wordpress/tests/compose.yaml run --rm -T cli wp eval-file - < wordpress/tests/assertions.php
python wordpress/tests/http-smoke.py
```

The local credentials above are exclusively for the loopback test environment. Do not use them in production. Assertions create test articles and a subscriber in this dedicated WordPress instance. ZIP installation is validated separately with source mounts removed, using `compose.packages.yaml`. No local previews are published. The packaged installation and functional checks passed on WordPress 7.1.3 / PHP 8.3.35.

After ZIP installation, `python wordpress/tests/admin-smoke.py` verifies the actual CMS login, setup form, CSRF protection and existing homepage preservation.

Phase 1 / 1.1.0: non-destructive navigation setup, shared topic taxonomy, primary topic and related exchanges. Run `wp eval-file - < wordpress/tests/navigation.php` in the local CLI container, then `python wordpress/tests/navigation-http.py`. A published test guide is created only in the isolated test database. Desktop dropdown and mobile collapse use a small standalone script; no-JavaScript navigation stays visible. Homepage composition is reserved for Phase 2.

1.4.0 fixes the first-install experience: the theme renders the confirmed dropdown navigation and all four near-top registration banners without requiring the plugin or seeded exchange records. Registration destinations remain centralized; missing offers are disclosed, never synthesized. `tests/layout-states.cjs` exercises initialized, uninitialized, and theme-only installations at desktop/mobile widths against the disposable Docker test site and restores its state afterward. It requires Playwright and Chromium (`CG_CHROMIUM_PATH`, default `/usr/bin/chromium`).

1.5.0 reorganizes the CMS administration: exchange CPTs share one menu; tokenized-stock and crypto desks aggregate authorized existing content by topic. An explicit nonce-protected action creates an attributed auto-draft. Empty exchange lists link to initialization. `tests/admin-content-http.py` covers menus, aggregation, input/CSRF protection, draft attribution and the empty-state notice.

1.6.0 opens registration banners directly through `/go/` in new tabs. Four centralized official defaults apply without seeded exchange records, while existing enabled valid referral URLs take precedence. `tests/direct-registration.php` checks precedence, expiry and unsafe-link fallback; `tests/direct-registration-browser.cjs` checks actual new-tab navigation with mocked external registration responses.

1.7.0 adds paginated related editorial content beneath each exchange hub using the existing private exchange associations. Checkbox selection supports multiple platforms; publication/password filters exclude nonpublic content, and hub cache invalidation follows content/association changes. `tests/exchange-content.php` covers types, exact ID matching, legacy metadata, privacy, pagination and cache notifications; `tests/exchange-hub-browser.cjs` covers rendered cards, sponsorship, pagination, article navigation and mobile layout with disposable fixtures.

1.8.0 adds an optional native-post review template, empty Gutenberg review pattern and editable provenance tables. Draft creation is explicit, idempotent per editor, and never publishes. Review policy is closed by default and requires a valid recommendation, verified official terms, product/country constraints, reader confirmation and a short-lived signed redirect; self-reported country is not KYC. Known SEO plugins take precedence over the built-in Article graph. Review block snapshots and source metadata use WordPress revisions. `tests/review-template.php`, `review-admin-http.py` and `review-browser.cjs` validate the policy, native draft/editor flow and rendered experience.

1.9.0 applies the simple editorial renderer automatically to native posts and existing editorial CPTs. Existing bodies/URLs/associations remain unchanged; TOC, related content and SEO no longer depend on choosing a special template. Standard editor blocks remain the default, advanced verification blocks stay optional. Article CTA restrictions continue; homepage registrations are unchanged. `tests/simple-article-browser.cjs` covers ordinary posts with existing associations and no template/primary-platform configuration, including mobile scroll, portrait images, Schema, TOC and closed-by-default CTA.

1.9.1 renders a semantic nested H2/H3 directory with chapter/subchapter numbering. Each author's independent sections stay independent; inline sources, fee tables and screenshots do not require separate chapters. The optional new-draft pattern demonstrates the owner's six review topics without changing existing content. `tests/simple-article-browser.cjs` now checks real desktop/mobile anchor navigation, keyboard folding, nesting/numbering, custom headings, duplicate anchors, no-heading articles and unchanged saved content/timestamps.

Plugin 1.9.2 adds explicit comparison-list inclusion to the native-post editorial metabox. `/compare/` and existing comparison-card shortcodes include legacy `cg_compare` plus opted-in public native posts, preserving original permalinks and platform associations. An isolated query filter excludes nonpublic/password content and avoids duplicate meta joins; comparison-page cache purge notifications follow inclusion/content/status changes. Theme 1.9.1 is unchanged. Run `tests/comparison-content.php` through the disposable CLI and `node wordpress/tests/comparison-browser.cjs` for query/privacy/authorization/cache checks and actual native-editor save/reload, both hubs, comparison tool, pagination and mobile layout.

1.9.3 shares `cg_article_cards_markup()` between exchange hubs and comparison lists, retaining the hub's image, excerpt, taxonomy, author/update-date and sponsorship presentation. Old theme/plugin combinations retain the existing hub display. `tests/article-cards-browser.cjs` compares actual content and computed card layouts in Binance, OKX and comparison contexts at 1440/768/390px, including covers, missing covers, Chinese excerpts and shortcode-free body fallbacks. It uses a self-contained tiny image by default; `CG_CARD_COVER` may point to a cover already copied into the disposable WordPress container for a representative local preview.

1.10.0 opens the existing crypto taxonomy root and child URLs as article directories, including empty desks. One scoped taxonomy template provides editable introductions, linked category filters, shared article cards, pagination, breadcrumbs and the existing four registration banners. Public main-query filtering excludes noneditorial, private and password-protected content; multi-topic posts appear once in the parent directory. Empty desks use noindex while populated desks preserve site privacy settings. Built-in CollectionPage/BreadcrumbList/canonical metadata yield to known SEO plugins. LiteSpeed tags invalidate all crypto directory and pagination URLs on content/category changes. Run `tests/crypto-archives.php` through the disposable CLI and `node wordpress/tests/crypto-archives-browser.cjs` for native taxonomy UI, archive filtering, routing, SEO, caching and desktop/tablet/mobile checks. No articles, category assignments, menu URLs or permalinks are generated or migrated during the update.

1.11.0 replaces the modular homepage with a linear editorial feed and responsive keyword search/registration sidebar. The homepage never outputs the global main post or the saved front-page body; excerpts are limited by characters independently of locale and never execute article shortcodes or blocks. An editor/admin order screen stores private positive priorities without editing articles, dates or taxonomy; unranked articles follow newest-first ordering. Scoped article search uses WordPress keyword relevance, excludes nonpublic/password/noneditorial records, and remains noindex with native or Rank Math robots. Home pagination works with both static-page and latest-post front settings, has canonical URL handling, and rejects out-of-range pages. Run `tests/home-content.php` through the packaged CLI and `node wordpress/tests/home-browser.cjs`; the older homepage/CMS/crypto checks were updated to assert the new layout while still preserving saved content.

`tests/home-rankmath-browser.cjs` exercises canonical/noindex with the official free Rank Math installed locally, including a pending wizard and the supported skip-account setup path. It requires an unconnected disposable site, restores its activation/setup/front-page/privacy state and removes its fixtures. Built-in metadata only yield to Rank Math once its frontend head hooks are initialized; an installed but unconfigured plugin does not leave the homepage without a canonical.


Theme 1.11.1 changes only the visible header brand anchor to the supplied DegenDeer / 鹿研社 mark, names and full Chinese subtitle. `assets/brand.css` is scoped to the brand component, and `assets/degendeer-mark.svg` is the supplied local decorative asset. Existing header container/navigation markup, menu JavaScript, homepage, search, registration sidebar, footer, database content/options and SEO output remain unchanged. The companion plugin stays at 1.11.0. Actual packaged WordPress browser checks compare the prior and updated theme at 1440/1024/390/320px, including mouse/keyboard/mobile menu use.


1.12.0 changes the existing `/exchanges/` archive into an editorial directory using the crypto archive layout and shared article cards. A main-query marker and EXISTS predicates include four-platform associations plus explicit comparison content, exclude platform records/nonpublic/password/unrelated posts, and avoid duplicates. The archive post type remains first in the query context for native routes and SEO while SQL restricts actual rows to editorial types. Native `/page/2/` pagination, empty noindex, cache-tag invalidation and scoped Rank Math variable/canonical compatibility are supported. Platform hubs, comparison URLs, brand, native articles and other directories remain unchanged. Run `tests/exchange-archive.php` via the disposable CLI, `node wordpress/tests/exchange-archive-browser.cjs`, and, with official Rank Math installed locally, `node wordpress/tests/exchange-archive-rankmath.cjs`. Tests create and clean local fixtures, restore privacy/setup options, and never connect a remote SEO account.
