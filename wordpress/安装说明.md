# 在你的 Hostinger 新网站安装

这两个 ZIP 分别是主题和插件，不需要购买其他插件，不需要新数据库或 VPS。WordPress 会使用 Hostinger 已建好的数据库。本安装只针对你新建的临时域名网站，不要在现有旅游网站执行。

## 安装顺序

1. 下载 `exchange-guide-plugin.zip`。WordPress 左侧「插件 → 安装插件 → 上传插件」，选择这个 ZIP，点击「现在安装」，然后「启用插件」。不要解压。
2. 下载 `exchange-guide-theme.zip`。左侧「外观 → 主题 → 安装主题 → 上传主题」，选择这个 ZIP，安装后「启用」。不要把主题 ZIP 上传到插件页面。
3. 左侧出现「交易所指南」。打开它，填写站点展示名称（暂用交易所指南），勾选「将新建的首页设为网站首页」，点击「创建基础页面并保存名称」。
4. 访问网站查看首页。如果目录或 `/go/` 显示 404，到「设置 → 固定链接」选择「文章名」，保存一次。

主题与插件需要 WordPress 6.6+、PHP 8.1+。如果上传时报权限、版本或其他错误，停在错误页并截图，不要进行一键重置。

## 你会得到什么

- 独立中文首页、可适应手机的布局和主导航。
- Binance、Bybit、OKX、Bitget、MEXC、Gate 六个资料页，仅预置名称，其他事实待你核验。
- `/compare/` 自选两家交易所比较，读取同一份费用与地区资料。
- 交易所评测、比较分析、推荐榜单、实用指南的后台内容类型和前台模板。
- 代币化股票专题入口、商业披露和比较方法基础说明。
- 在交易所编辑页集中管理推荐链接、有效期与累计点击。

初始化只增加缺少的资料和页面，重复运行不会覆盖已有正文或交易所字段。有同名已有页面时会保留它并显示提示；需要核实对应页面是否放入正确的短代码。勾选首页选项会改变当前新网站的首页设置。

## 编辑交易所与推荐链接

点击左侧「交易所资料」，选一家「编辑」。页面底部「资料核验与推荐链接」框可填写费用条件、地区资格、来源、核验日期和你的推荐 URL。推荐功能只允许管理员修改。

链接必须为完整 HTTPS 地址，且属于该交易所登记的官方域名。错误域名会被拒绝，并停用推荐入口。正确后勾选「推荐链接已核实并启用」，再保存。

入口统一是 `/go/binance/`、`/go/bybit/`、`/go/okx/`、`/go/bitget/`、`/go/mexc/`、`/go/gate/`。失效入口返回资料页，不会跳到任意网站。有效期到所选日期的 **00:00 UTC** 即停用；北京时间为当天 08:00。

通过推荐入口的统计只累计点击，包含重复访问与可能的机器人请求，不能当作注册转化。不保存访客 IP、邮箱、钱包或额外跟踪 Cookie；服务器自身日志由你的托管服务管理。

若官方推荐 URL 使用其他区域域名或短链，不要随意改成允许域名，先核实并交由开发人员增加明确允许项。

## 写评测、比较与指南

对应左侧「交易所评测」「比较分析」「推荐榜单」「实用指南」。新建内容、设定清晰英文网址标识，填写正文与摘要。先保存草稿，核验后发布。

示例路径：

- 交易所资料：`/exchanges/binance/`
- 评测：`/reviews/binance-review/`
- 比较分析：`/compare/binance-vs-bybit/`
- 场景榜单：`/best/best-crypto-exchanges/`
- 操作指南：`/guides/binance-deposit/`

文章里添加「短代码」区块，输入 `[cg_affiliate exchange="binance"]`。它会自动使用中央配置和披露，不需要把完整推荐链接粘贴到正文。新增内容会出现在相应目录和首页区域，没有文章时显示准备中，不编造内容。

## 缓存设置

你已安装 LiteSpeed Cache。到「LiteSpeed Cache → 缓存 → 排除（Excludes）」的「不缓存 URI（Do Not Cache URIs）」中加入以下两行（保留已有规则）：

```
/go/
/compare/
```

保存后清除缓存。插件也会对推荐响应发出禁止缓存和禁止索引指令，但缓存插件/服务器已有的缓存必须排除。更换推荐链接后测试跳转目的地。

## 暂时不要开放搜索索引

建站期间保留「设置 → 阅读 → 建议搜索引擎不索引本站」。该设置是搜索引擎提示，不能作为访问密码或隐藏网站的措施。

上线前还需要真实且有来源的资料、正式品牌与域名、适用的隐私与联系页面，以及根据实际商业活动复核披露说明。插件不生成未经确认的费用、评分或优惠。

本版本前台只提供简体中文；未来多语言、外部分析、广告管理和自动资料同步需要后续实现。WordPress 自带的标题、规范 URL 和站点地图可用，专业 SEO 设置可后续接入；本插件不附带完整结构化数据或 SEO 优化承诺。

停用主题或插件不会删除已保存的内容。不要删除数据库；切换主题前先备份。自定义字段暂未提供独立的历史审计界面。

## 1.1.0 更新：Phase 1 导航与分类

先备份当前 WordPress 网站，然后在原来的网站上传新版插件和主题 ZIP。WordPress 提示已有版本时选择替换当前版本；不要先删除插件或数据库。

到「交易所指南」点击 **应用已确认的导航与定位**。该按钮将本功能管理的新菜单设为主导航，保留旧菜单。自定义品牌名称会保留；默认的「交易所指南」会调整为「加密资产投资与数字金融指南」。

菜单为：

- 交易所：Binance / OKX / Bitget / Bybit / 交易所对比。
- 美股代币：交易指南 / 出入金指南。
- 加密货币：新手入门 / 钱包与资产安全 / 出入金 / 加密货币理财。

MEXC、Gate 仅移出导航，资料页和推荐配置保留。后台可在「外观 → 菜单」编辑菜单，在各内容类型的「内容主题」管理分类。在文章底部还可选择主要主题与关联交易所。

没有已发布内容的主题会显示为不可点击标签，其分类地址返回 404，不生成空分类文章。发布并关联主题后入口可用。Phase 1 仅调整导航、定位和分类；首页 Hero 和模块将在 Phase 2 改版，本版本不宣称首页已改成综合媒体布局。

应用后清除 LiteSpeed Cache 和浏览器缓存，检查新导航。

## 1.2.0 更新：文章注册入口与注册说明页

文章详情页右侧展示 Binance / OKX / Bitget / Bybit 注册卡片，手机端放在正文后。点击进入 `/register/binance/` 等本站注册说明页，再通过已配置的 `/go/` 前往交易所；未配置推荐链接时不会虚构活动。注册说明页暂不参与搜索索引。

在「交易所资料」编辑对应交易所，可选择「注册横幅图片」。只上传原创或获得授权的图片，建议约 4:1；留空使用深蓝与青绿色文字卡片。已有推荐链接、条款、有效期设置继续使用。也可在页面加入 `[cg_registration_cards]` 展示四家入口。

替换两个 ZIP 后，点击「应用已确认的导航与定位」刷新地址规则，然后清除 LiteSpeed Cache。本文更新不会修改首页模块或批量发布文章。

上传后「替换当前版本」并启用主题/插件，再清除 LiteSpeed Cache。已有文章、菜单、推荐链接与横幅图片不会被删除或重置。

## 1.6.0 更新：横幅直接打开注册页

同时替换主题和插件至 1.6.0，然后清除 LiteSpeed 页面和 CSS/JS 缓存。首页及文章侧栏的四条横幅改为新标签页打开 `/go/{exchange}/`，立即 302 跳转到外部注册页，不再经过本站注册说明页。

默认目的地集中保存在插件中：

- Binance：`https://www.binance.com/en/register`
- OKX：`https://www.okx.com/join`
- Bitget：`https://www.bitget.com/register`
- Bybit：`https://www.bybit.com/en/register`

这些默认链接不带本站推荐码。无需录入平台资料或手动勾选推荐启用，也会使用官方入口。现有有效且已启用的推荐链接优先，不会被覆盖。

以后到「交易所管理 → 交易所资料」编辑平台，填写自己的完整推荐链接，勾选「推荐链接已核实并启用」，保存并清除缓存。首页、侧栏和短代码横幅将通过同一 `/go/` 自动使用新链接。推荐链接未启用、过期或域名不合法时，四家平台回到官方注册链接；其他平台保留原有配置逻辑。

官方入口与推荐入口的横幅文字、`sponsored` 属性和披露说明按实际配置切换。平台资料、评测和导航链接继续用于阅读内容；旧注册说明页面保留，避免破坏已有地址。未安装新版插件时，主题显示入口待配置，不虚构外部链接。

本地测试验证了 302 目的地、后台链接覆盖、过期/无效链接回退、反注入保护和浏览器新标签页行为；浏览器测试拦截外部站点，仅验证导航，不提交真实注册表单。

尚未编辑平台正文不影响相关文章汇总；正文和费用等资料可以逐步完善。页面仍明确保留未核验状态。

## 1.8.0 更新：原生文章评测发布模板

同时替换主题和插件至 1.8.0，确认启用，清除 LiteSpeed 页面和 CSS/JS 缓存。原有专题、文章、数据和首页注册入口保持；本次增加可复用的评测模板。

### 创建首篇草稿

进入「交易所管理 → 评测发布模板」，点击「创建或继续编辑币安评测草稿」。新内容是 WordPress 原生文章（`post`），不是静态页面，预设用户指定的完整标题、评测模板、Binance 关联、评测分类和空白章节。只有你点击按钮才创建，且不自动发布。重复点击会打开已创建的记录。

其他平台：到「文章 → 新建」，在文章设置选择模板「交易所评测」，从区块模式插入「交易所评测 · 空白核验结构」，在底部「评测模板 · 平台、来源与 SEO」选择主要平台。旧的 `cg_review` 内容也可选择该模板，不需迁移。

摘要、特色图片/图片说明/替代文字、分类、作者、发布时间和正文均使用原生编辑器。正文使用 H2/H3，显示时自动生成目录并处理重复锚点；正文里的 H1 在显示层转换为 H2，后台原文不变。费用、参数与地区说明放在文章，不改变简短的平台专题介绍。

### 填写核验表

预设十项参数名称和四项费用项目，不填任何数值、测试结论、收益率或用户评价。每行可编辑项目、资料、适用条件、来源名称/HTTPS 链接、核验日期和状态。只有人工选择已核验，并有数值、有效来源与非未来的真实日期时，才展示结论；不完整或需重新核验的记录显示未核验状态。系统检查记录完整性，不代替编辑核实事实。

区块数据随正文修订保存，文章来源/平台/SEO/核验日期元数据支持原生修订。独立评测保留自己的资料快照，不自动用最新平台资料替换旧数据。实测章节只使用编辑上传的真实截图，并在图片说明中记录测试日期、环境和条件。没有真实测试材料就删除或暂不完成该章节，不使用虚构描述。

主要平台保存后自动同步专题关联。文章发布后进入 Binance 专题；相关文章模块排除自身、草稿、私密和密码保护文章，优先同平台相关主题内容。没有已发布相关文章时不生成空内链。

### 评测 CTA 与地区条件

评测模板不显示默认四家注册横幅；插入旧的推荐/横幅短代码也不绕过评测限制。CTA 默认关闭，普通首页横幅仍保留之前明确授权的官方注册行为。

管理员在「评测推荐展示规则」配置产品、明确允许的 ISO 两位地区代码、平台官方域名的条款链接、实际条款核验日期和截止日期，并启用已经核实的推荐链接。没有这些完整有效记录，不会给出推荐入口，也不会回落到官方注册链接。

读者主动填写所在地并确认条款，服务端复核条件后才返回有效期十分钟的签名链接。专用受限跳转会复核地区、有效期、政策、合作链接及签名，缺失/篡改/过期均拒绝。地区自报不能证明真实居住地、年龄或 KYC，最终产品资格由平台决定。该规则不宣称自动完成法律合规审查。

缓存插件/服务器请排除 `/go/review/` 和 `/wp-json/cg/v1/review-eligibility`，不得缓存个性化授权响应；代码同时发出禁止缓存/索引指令。推荐规则字段仅管理员可修改，其他编辑人员可维护正文与编辑资料。

### SEO 与上线前核对

模板输出摘要/自定义描述、Article、BreadcrumbList、实际作者与发布日期/更新日期、OG 分享信息；未填图片不伪造图片，未填评分不生成评分 Schema。核验日期与文章更新时间分别显示。规范网址使用 WordPress 原生输出。检测到 Yoast/Rank Math/AIOSEO 时让出自定义 SEO 输出；其他插件可通过 `cg_review_builtin_seo` 过滤器关闭本模板输出，避免重复。

模板创建的是空结构。发布前人工完成结论、优缺点、真实产品分析、逐项来源和核验、风险说明、真实截图（如有）及披露。缺少材料时保留草稿，不把“2026 全面分析”标题当作已经完成核验的证明。

本地验证覆盖了原生编辑器实际编辑/保存、专题归属、未核验数据隐藏、地区条件/签名防篡改、目录、Schema、相关文章与手机表格滚动。没有在用户 Hostinger 发布任何文章。

## 1.9.0 更新：普通文章直接使用简洁媒体排版

同时替换主题和插件至 1.9.0，确认启用，清除 LiteSpeed 页面和 CSS/JS 缓存，然后打开你已经发表的文章即可。不用选择专用评测模板，不用搬正文，不改变文章地址或专题关联。

普通文章、评测、对比、榜单和指南共用简洁布局：标题、原生摘要、作者/发布/更新时间、特色图、H2/H3 自动目录、普通正文/表格/图片、文末来源/风险说明和相关文章。桌面正文旁放紧凑目录和专题入口，手机端目录置于正文前。长表格横向滚动、手机截图按合理尺寸居中显示。目录只修改显示层锚点，不写回正文；如原文已手写目录，删除旧目录块可避免重复。

继续在原生编辑器中写段落、标题、图片和普通表格。来源与核验日期可写在对应段落、表格或图片说明旁；不要求填写复杂参数表单。旧核验区块和旧模板保留兼容，已有资料不会被删除。后台「文章补充设置」可不填写；SEO 描述默认读取文章摘要，平台自动读取已有「关联交易所」。

普通已发表文章现在也自动输出 Article、BreadcrumbList 和基本分享元数据；检测已知 SEO 插件时让出输出，避免重复。作者、时间和图片读取实际 WordPress 字段，不生成评级或核验结论。

新建文章可直接点击「文章 → 新建」。可选的「金融文章 · 简洁结构」只提供普通章节；币安草稿创建入口也改为普通区块，不设置专用模板、不自动填数据或发布。现有内容无需使用该入口重建。

文章页不无条件展示注册横幅；之前配置的地区/产品/合作规则及受限跳转仍保留，首页官方注册横幅不变。推荐入口是可选功能，不是写作步骤。
