# 文章列表首页、可调顺序与关键词搜索 · 1.11.0

## 对应需求

1. 移除首页底部意外输出的整篇文章。旧 `front-page.php` 最后推进主循环并调用 `the_content()`，在「最新文章」首页模式下会输出第一篇文章正文；新版独立查询并只显示短摘要，不推进全局主循环。
2. 从首页移除「开户注册前确认」和「让信息有依据，让风险看得见」大块说明，以及旧的大幅介绍和多段分类宣传模块。页脚与注册入口旁的风险、商业披露继续显示。
3. 首页直接显示单列文章：标题、日期、作者、内容主题、赞助标识、特色图片、短摘要与阅读全文。桌面右侧为关键词搜索与四家注册横幅；手机搜索在列表上方，横幅在列表下方。仅参考媒体首页的信息组织，没有复制 Murmurcats 的品牌、图片、文章或视觉素材。

## 实现与保留

- 新增「网站管理 → 首页文章排序」（编辑者从「文章」进入）。以数字 1～9999 排序，数值越小越靠前；留空按发布时间、ID 倒序。同篇文章不会重复显示。排序只更新私有元数据，不改正文、网址、发布时间和分类。
- 首页每页 8 篇，搜索每页 9 篇，复用原生文章和四类已有编辑内容；明确排除草稿、私密、密码文章、普通页面及平台资料。
- 搜索使用 WordPress 原生关键词相关性及 SQL 转义，支持中文、英文、正文和引号短语、分页与无结果反馈。摘要按字符限制为最多 140 字符，不执行区块或短代码，不受英文环境下中文没有空格的影响。
- 标题、图片、摘要及链接输出转义；表单保存使用 nonce、角色与逐篇编辑权限，并在修改前验证完整批次。
- 首页分页使用自身 canonical，越界页返回 404。搜索 noindex 同时覆盖原生 WordPress 与 Rank Math；不修改用户全站索引设置。
- Rank Math 未完成设置时可能尚未注册前台 SEO 输出。兼容判断改为检测实际 head hook，接管前保留内置元数据，接管后让出输出。
- LiteSpeed 首页缓存标签覆盖所有首页分页，正文、发布状态、排序、缩略图、赞助标识及分类变化通知清除。现有交易所专题、比较页、加密货币分类、文章目录、集中注册入口及导航继续使用。

## 验证

实际 ZIP 安装于隔离的本地 WordPress 7.1.3／PHP 8.3，未登录或修改 Hostinger 后台。

- `home-content.php`：35 项收录、排序、去重、分页、隐私、nonce／权限／整批输入验证、幂等性、缓存及原文章保留检查通过。
- `home-browser.cjs`：静态与最新文章两种首页都不输出正文；真实后台表单排序、重载、清空恢复、管理员及编辑者操作、未授权拒绝、中文／英文／短语搜索、分页、无结果、特殊字符转义、空及数组关键词通过。
- 在 1400／768／390px 验证首页与搜索无整页横向溢出；手机搜索位于长列表之前，菜单通过实际点击展开，四家横幅及安全的新标签页属性保留。浏览器鼠标停在 WordPress 工具栏会触发管理下拉浮层，测试改为将指针移到正文空白区域，再执行真实点击；没有隐藏工具栏或强制点击。
- `homepage-http.py`、`navigation-http.py` 与其 CMS／全站冒烟依赖通过；已保存的首页正文在数据库中保留，但不再拼到前台文章列表后面。
- `crypto-archives-browser.cjs` 的原生后台多分类、专题收录、筛选、目录 Schema、noindex 和三种宽度回归通过。
- `article-cards-browser.cjs` 验证 Binance／OKX／比较列表三种宽度的共享卡片内容及实际计算样式继续一致。
- 核验官方 Rank Math 1.0.280 ZIP 后安装于本地；`home-rankmath-browser.cjs` 在向导未完成、官方免费「跳过账号连接」两种状态下，分别检查两种首页模式：首页与第 2 页只有一个正确 canonical，搜索及空分类 noindex 均通过。测试未连接外部账号，已恢复插件启用、设置、隐私及首页状态。
- PHP／JavaScript／Python 语法、Git 空白、ZIP CRC 与源码一致性检查通过；独立审阅未发现阻塞问题。
