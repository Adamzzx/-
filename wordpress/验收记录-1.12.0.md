# 交易所文章总页 · 1.12.0

## 对应需求与范围

把原有 `/exchanges/` 的平台资料归档改为与「加密货币」栏目相同的文章目录：纯文字标题「交易所」、面包屑、简介、六个入口、共享文章卡片、分页、四家注册入口侧栏和移动端堆叠。品牌与导航脚本继续使用 1.11.1 的现有实现。

分类入口使用既有地址：全部文章、Binance、OKX、Bitget、Bybit、交易所对比。没有新建平台页、对比页、文章或分类，也不改变现有正文、作者、时间、网址、专题关系和推荐设置。

## 实现

- 插件新增 `exchange-archive.php` 并加载：主查询与辅助查询使用一致的公开可见性与文章筛选，四家关联或明确对比内容自动收录。SQL 使用 EXISTS，允许多平台／多行元数据而不重复卡片；显式排除平台资料类型与未公开、密码内容。
- 为保留 WordPress 的原生档案上下文，查询中的 `cg_exchange` 保持第一位；SQL 实际只返回五类编辑内容。局部模板层级过滤选择新的主题归档模板；原生分页和越界 404 保留。
- 主题新增 `archive-cg_exchange.php`：完整复用加密货币页样式、`cg_article_cards_markup()` 和注册入口侧栏，没有重新实现另一套卡片或全局样式。
- `index.php` 归档标题先剥离标签再转义，修复字面显示 `<span>` 的问题；归档正文和其他列表结构不改。
- 内置 CollectionPage、BreadcrumbList、description、canonical 在 SEO 插件接管后让出，空列表 noindex，保留全站隐私设置。Rank Math 某些档案变量会使用首篇文章类型而显示 Posts，本次用仅针对本目录的 replacements 过滤修正，保留站长的标题模板。
- LiteSpeed 的目录缓存标签覆盖所有分页；文章、关联、对比标志、封面、赞助标记、主题及作者显示信息变化会通知清除。
- 自定义内容插件与主题版本均为 1.12.0，无数据库迁移或初始化操作。

## 验证

在隔离的本地 WordPress 7.1.3／PHP 8.3 安装实际生成的 ZIP 验证：

- PHP 目录套件通过：所有平台关联、普通与旧内容、对比标志、字符串旧 ID、重复元数据、主／辅助查询、分页、稳定排序、匿名／管理员隐私、未关联及旧平台排除、其他查询与加密货币目录独立、原始正文／网址／关系保留、缓存失效。
- 浏览器套件通过：真实目录路由、六入口、文章去重、封面和元信息、四横幅及安全新标签页属性、原生第2页和越界404、CollectionPage/BreadcrumbList、规范链接、空态和隐私。
- 1440／1024／390／320px 的卡片计算样式与加密货币栏目逐项比较一致，整页没有横向溢出；真实桌面下拉和手机菜单进入 Binance 专题正常，文章详情与既有 Hub 均可打开。
- 官方 Rank Math 在向导未完成和免费跳过账号连接、前台输出启用两种状态下通过：正确归档模板／标题、单一 canonical／description／CollectionPage、原生第2页与全站 noindex。未连接外部账号，测试后恢复启用、设置和隐私状态。
- 修改 PHP 语法、JavaScript 语法、Git 空白、ZIP CRC 与源码一致性检查通过。

测试仅在本地创建并清理临时内容，没有登录或修改 Hostinger。预览使用用户已公开的标题、摘要与封面，在本地临时记录中展示；截图后删除记录并恢复作者及推荐显示状态。没有将测试内容发布到正式网站，也没有改写文章金融数据。
