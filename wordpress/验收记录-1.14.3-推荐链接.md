# 插件 1.14.3：已核实的推荐域名

## 原因与修复

原插件仅允许四家交易所的预设官网域名。即使管理员勾选了“已核实并启用”，交易所官方提供的其他推荐域名也会被拒绝，入口回退到官网。区块编辑器的文章保存提示没有准确反映这次推荐设置的校验失败。

新版沿用原来的“注册或推荐链接”输入框及启用复选框。可编辑该交易所的网站管理员填写完整 HTTPS 链接并勾选后，为当前交易所授权链接中的完整域名。Binance、OKX、Bitget、Bybit 都使用同一流程，不需要另填域名，也没有在插件包中写入站长个人的推荐链接。

授权绑定交易所对象、平台别名和完整域名，不自动扩展到其他子域名或其他平台。网址不得包含用户名、密码、自定义端口、IP 地址或本地域名。官方条款链接仍使用原官网校验规则。域名来源由管理员核实，插件不声称已替管理员验证商业合作关系。

输入不合法时保留原有有效推荐配置，并显示“推荐设置未保存”的明确错误。链接栏下方显示已保存的实际状态和目标域名。停用、清空或到期时继续使用现有官方注册入口。更新推荐配置后发出 LiteSpeed 全站页面缓存清理通知。

## 修改文件

- `plugin/exchange-guide/exchange-guide.php`：接入推荐设置校验和实际状态，版本更新为 1.14.3。
- `plugin/exchange-guide/referral-settings.php`：域名授权、配置保存、权限检查、私有状态查询及缓存通知。
- `plugin/exchange-guide/assets/referral-admin.js`：区块编辑器中的保存结果提示，并校验结果属于本次保存。
- `tests/referral-destinations.php`、`tests/referral-destinations-browser.cjs`：隔离测试及恢复原数据；既有 `tests/assertions.php` 调整为“拒绝无效修改并保留原配置”的断言。

主题、导航、文章正文、图片、SEO、永久链接、统计代码和站点地图均未修改。

## 实际验证

在专用 `exchange-guide-pagination-test` 本地 Docker 项目中，通过最终 ZIP 替换安装插件，没有源文件挂载。环境为 WordPress 7.1.3、PHP 8.3.35、官方 Rank Math 1.0.280。没有连接或操作 Hostinger 生产数据库。

最终 PHP 测试和真实浏览器测试均通过，日志见 `audits/referral-domains-php-20261023.log`、`audits/referral-domains-browser-20261023.log`。验证包括：

1. 四家交易所的自定义推荐域名启用、完整域名及平台隔离、停用/到期/清空回退。
2. 原生 Gutenberg 实际填写、勾选、保存、刷新及读取已保存状态。
3. 匿名 `/go/okx/` 返回 302，保留原路径与推荐参数；测试只读取跳转响应，不访问外部注册网站。
4. 普通推荐点击计数增加一次；管理员访问不计数；配置保存不记录点击。点击不代表注册成功。
5. 首页与主题页侧栏共用中央入口，推荐披露和 sponsored 标记正确；文章入口仍要求现有地区及阅读确认流程。
6. HTTP、带身份信息等无效网址明确报错，旧有效配置保留，刷新后错误仍可见，之后有效保存清除错误。
7. 缺少/错误 nonce、匿名状态查询及不足权限不能读取或修改推荐配置。测试后恢复原交易所数据与计数。
8. PHP/JavaScript 语法、Git 空白、ZIP CRC 和包内文件与源码一致性检查。

WordPress 6.6 的旧保存过滤器兼容已按核心代码接入，但本次没有另外搭建 6.6 环境进行浏览器验收。生产缓存清理、线上跳转以及真实交易所推荐归属尚未由本次测试验证。

## 应用与线上验收

先保留当前插件和数据库备份。下载 `dist/exchange-guide-plugin-1.14.3.zip`，在 WordPress「插件 → 安装插件 → 上传插件」上传，选择替换“数字金融指南 · 内容与推荐管理”。本次只需更新插件，保留现有主题。

替换后重新打开 OKX 交易所编辑页，重新粘贴自己的完整推荐链接，勾选“已核实并启用”，保存。原版本可能已经拒绝保存该链接，因此不能只安装新版而不重新保存。确认链接栏下显示“推荐入口已启用，目标域名：www.topfgcnzqwl.net。”。其他三家分别保存各自核实过的链接即可。

清除实际启用的 LiteSpeed 页面缓存；如 Hostinger 另有页面/CDN 缓存，也清除对应缓存。使用未登录窗口点击横幅，确认 `/go/okx/` 首次 302 的 Location 是刚保存的完整推荐网址。交易所后续可能自行跳转到其他页面，应以本站首次跳转和交易所实际推荐归属分别核验。

本次没有生产后台登录权限，因此没有把本地验证说成线上已生效。上述上传、重新保存及生产验收仍需在真实站点完成。

## 回滚

上传保留的旧插件包，或仓库中的 `dist/exchange-guide-plugin-1.14.2.zip`，选择替换并清除页面缓存。没有数据库表结构迁移。旧版不能使用这些额外推荐域名，将按旧规则回退至官方注册入口；新版的私有授权元数据可保留。回滚不需要删除文章或修改主题。
