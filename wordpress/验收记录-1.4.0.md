# 1.4.0 交付验收范围

本次修复：一级导航下拉箭头、确认的全部二级入口、首页上部开户注册横幅，以及首次启用/未初始化时的展示与注册页访问。

| 要求 | 验收方式 |
| --- | --- |
| 交易所 / 美股代币 / 加密货币一级导航与箭头 | 浏览器确认三个标题、三个 SVG 箭头；点击展开，再点击收起 |
| 确认的二级标题与顺序 | HTML 与浏览器检查，默认导航与后台管理菜单两种方式 |
| Binance / OKX / Bitget / Bybit 注册横幅 | 首页上部固定展示四条原创横幅，不依赖录入交易所资料 |
| 手机端菜单与横幅 | 390px 浏览器验证菜单折叠、二级展开和页面无横向溢出 |
| 插件未启用、未初始化、已初始化 | 三种状态均实际加载页面并截图检查 |
| 缺少推荐链接 | 注册说明显示待配置，不虚构优惠或链接 |
| 已有推荐链接 | 继续通过 `/go/` 进行域名校验、重定向和缓存控制 |
| 保留原有功能与数据 | 比较、注册页、文章发布状态、导航配置回归测试；不批量生成文章，不重置现有内容 |

测试位置：本地 Docker WordPress，不代表已替用户更新 Hostinger。需要用户上传替换主题与插件、启用并清除缓存。

本次不宣称已补齐全部长期路线图功能；文章内容、正式品牌/域名、完整 SEO Schema 和多语言仍按实际实现进度推进。
