# 评测发布模板 1.8.0 验收

| 用户需求 | 实现与验证 |
| --- | --- |
| 原生文章管理 | 原生 `post` + 可选择 PHP 评测模板；标题、摘要、正文、分类、作者、图片和时间由 WordPress 管理 |
| 可复用媒体布局 | 专用文章头部、特色图、目录、正文和相关文章；十个章节为空白结构，内容不写入 PHP |
| 十项参数与费用表 | 原生可编辑区块，预设名称，无数值；逐项来源、条件、日期和核验状态 |
| 不虚构数据/实测 | 未核验数值不展示，不创建测试结论/评分/截图/用户评价；实测图片由编辑提供 |
| Snapshot 与核验 | 数据存正文区块、资料元数据支持原生修订；发布日期、更新时间与核验日期分开 |
| Affiliate 限制 | 默认关闭、不加载评测侧栏横幅；条件确认 + 服务端策略/合作链接检查 + 十分钟签名；未知/拒绝地区无链接 |
| 地区控制边界 | 按读者主动申报与管理员核验规则判断，不宣称 IP 定位、法律审核或 KYC 证明；旧首页入口不变 |
| 自动 Binance 归属 | 首篇草稿预设主平台；保存平台自动关联；改变平台更新自动关联 |
| 自动相关文章 | 现有专题关联查询；排除当前、非公开和密码保护文章；优先同主题 |
| 移动端与表格 | 390px 页面无横向溢出，表格容器横向滚动；目录可折叠 |
| 标题与目录 | 一个显示层 H1；H2/H3 自动目录；重复锚点重新编号，后台原文不变 |
| Breadcrumb/Schema/SEO | Article + BreadcrumbList，实际作者/时间/图片，无评分；描述和 OG；检测已知 SEO 插件后让出输出 |
| 权限与草稿 | CSRF 校验、管理员专属政策；手动创建原生草稿、重复操作复用，不自动发布 |

验证环境：本地 Docker WordPress。测试稿、占位图和规则仅用于本地功能检查，测试结束删除。未向 Hostinger 发布文章，未提交任何真实交易所注册表单。

测试：`review-template.php`、`review-admin-http.py`、`review-browser.cjs`，以及原有推荐/文章/后台回归检查。编辑器测试包含实际编辑字段、保存并检查前台值；浏览器检查目录、Schema、表格、来源、图片与受限链接。
