# 正文章节与两级目录 1.9.1

本次增量修改集中在正文目录、可选新草稿示例与编辑说明。模板不规定作者必须使用哪些章节，不写回现有文章正文。

- 将 H2/H3 的平铺缩进列表改为实际嵌套列表，显示章节/子章节编号并直接跳转到相应标题。
- H3 归于前一个 H2；文章以 H3 开始时保留可访问入口，不虚构父标题。重复锚点在显示层去重，手写目录标题不列入自动目录。
- 可选新草稿使用「核心结论、支持的地区、注册与 KYC、出入金、手续费、理财产品、美股支持情况、风险提示」，章节可以增删、改名或排序，不批量套入现有内容。
- 截图、费用说明、来源与核验日期跟随相应正文；不要求额外设置截图/手续费来源章节。来源清单留空不生成文末来源模块。
- 桌面目录支持长列表滚动，手机目录支持键盘/点击折叠；表格仍在容器内横向滚动。

验证使用安装 ZIP 的本地 WordPress 7.1.3 / PHP 8.3 环境，不连接 Hostinger 后台，也不发布线上内容。预览图为排版示例，图片来自用户已有公开文章，不构成产品/收益/测试信息核验。

通过的验证：

- `simple-article-browser.cjs`：普通文章六个独立主题及结论/风险章节、H3 真正嵌套与编号、电脑/390px 手机锚点跳转、目录键盘折叠、截图在理财章节内、表格横向滚动、无标题/重复锚点/自定义章节，保存正文和更新时间未改变。
- `review-admin-http.py`：原生草稿与后台实际提交、六个主题独立成章、无强制截图/来源章节、CSRF 防护、重复点击保留同一草稿、原首页设置保留。
- `review-template.php` 与 `review-browser.cjs`：旧核验区块实际编辑保存、原生修订字段、专题关联、未核验数据不展示、Article/BreadcrumbList、地区及签名推荐规则、手机表格滚动继续通过。
- PHP 语法检查、上传 ZIP 完整性与 `git diff --check` 通过。
